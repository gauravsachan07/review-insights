# Example weekly pulse (illustrative)

> Illustrative example only. A real run generates this from
> `data/reviews.csv` via the LLM; wording varies by model. The quotes below are
> verbatim from the sample CSV. No secrets are included.

## Top themes

1. **Exit load confusion** — charges on early mutual-fund redemption that users
   only discover after the fact.
2. **App usability** — smooth onboarding and UPI flows; some fee screens hide
   details until the last step.
3. **Support responsiveness** — fast resolutions for KYC and settlement
   questions, but fee questions take several chats.

## Customer quotes

> "Why is exit load not shown at the time of purchase?" — R002 (1★)

> "I redeemed my SIP early and saw an exit load deduction in the statement." — R004 (1★)

> "Exit load confusion cost me money." — R009 (1★)

## Key observation

The single recurring fee complaint is **exit load** on early redemption. Users
do not object to the fee existing; they object to learning about it only after
redeeming, with no tooltip, FAQ link, or confirmation warning.

## Action ideas

1. Show an exit-load note on the fund page and in the redemption confirmation.
2. Add a short in-app explainer (what it is, when it applies, how it is computed).
3. Link the fund FAQ to an official source (Groww exit-load page / AMFI / SEBI).
